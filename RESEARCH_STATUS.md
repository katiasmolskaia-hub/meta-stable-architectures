Это навигация по последовательности проверок Meta-Stable Architectures. Результаты относятся к конкретным вычислительным моделям. Общая архитектура, физический рой и научная новизна этими опытами не доказаны.

|---|---|---|
| Обратная связь мостового механизма | Простой цикл «отказ → пауза → проба» оказался сильнее тяжёлого жизненного цикла в исследованном стенде. | [7 сентября](manuscripts/v6/bridge_feedback_results_2026-09-07.md) |
| Буфер | Обычный буфер помогает при несовпадении времён передачи; дополнительное стрессовое разрешение не дало преимущества. | [3 октября](manuscripts/v6/bridge_buffer_results_2026-10-03.md) |
| Выбор соседей | Наблюдаемый опыт полезнее случайных обменов; большая часть выигрыша уже доступна по последнему контакту. | [3 октября](manuscripts/v6/bond_rewiring_results_2026-10-03.md) |
| Размер и цена перестройки | Часть выигрыша сохранилась при 24–96 узлах и повышении стоимости, с ограничениями по сценариям. | [3 октября](manuscripts/v6/bond_rewiring_scale_cost_results_2026-10-03.md) |

## Воспроизведение

Код находится в `simulations/`, протоколы — в `manuscripts/v6/`. Архив [research_results](research_results/README.md) содержит исходные CSV, конфигурации, снимки кода и имеющиеся графики десяти итоговых серий. Варианты, исправленные после численных проверок, обозначены `v2`; ранние промежуточные папки не являются итоговыми данными.

```sh
python -m pip install -r requirements-research.txt
python -m unittest discover -s simulations -p 'test_*.py'
python simulations/experiment_support_pulse.py
python simulations/experiment_support_pulse.py --step-check
python simulations/report_support_pulse.py
python simulations/check_support_pulse_traffic.py
python simulations/plot_support_pulse.py
python simulations/experiment_support_pulse_cost.py
python simulations/experiment_support_pulse_cost.py --step-check
python simulations/report_support_pulse_cost.py
python simulations/plot_support_pulse_cost.py
python simulations/experiment_local_agreement.py
python simulations/report_local_agreement.py
python simulations/experiment_recovery_history.py
python simulations/report_recovery_history.py
python simulations/plot_recovery_history.py
```

Новые расчёты пишут в игнорируемую Git папку `outputs/` и отказываются перезаписывать основные CSV. Для просмотра сохранённого опыта ничего запускать не нужно: отчёты и таблицы доступны прямо в архиве. Для построения отчёта из архивных данных скопируйте нужную папку из `research_results/` в `outputs/` под тем же именем. Снимки исполняемого кода в архиве предназначены для проверки точного происхождения данных; запускайте рабочие модули из `simulations/`.

Зависимости перечислены диапазонами совместимости; точные версии Python и NumPy каждой серии записаны в её конфигурации. Воспроизведение дискретных перестроек на другом окружении не обязано быть побитовым. Графики требуют Matplotlib. Результат контрольного опыта не следует переносить на другой эксперимент с иной геометрией, динамикой или доступностью соседей.

Незавершённые локальные черновики раннего Volume VI не включены в эту исследовательскую подборку. Уже существовавшая история коммитов сохранена.
