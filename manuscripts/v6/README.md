# Volume VI Working Folder

This folder holds the working transition from Volume V toward Volume VI.

The purpose is not to freeze a final theory yet, but to preserve the emerging direction in a stable written form so that the next stage can be developed without losing continuity.

Current working center:

- living field memory,
- route-like memory,
- collective re-bonding under stress,
- re-entry into the field after crisis,
- field-led diagnosis rather than single-metric diagnosis.

The documents here are intentionally early and structural.
They should help track direction, roles, and candidate experiments before a full manuscript architecture is opened.

## Suggested internal structure

The folder is now best read as four layers rather than as one flat list.

### 1. Entry files

These are the best files to read first because they explain why Volume VI exists and what its main opening problem is.

- `volume_V_to_VI_transition.md`
- `volume_VI_concept_skeleton.md`

### 2. Core architecture files

### 3. Bond-dynamics working files

- keep the entry files,
