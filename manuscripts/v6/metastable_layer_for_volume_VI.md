# Metastable Layer for Volume VI

## Why this file matters

The current Volume VI route model already works as a diagnostic architecture.

But it is still too clean in one important sense:

- the crisis routes are readable,
- the interventions are readable,
- and the outcomes are often more orderly than a living field would be.

The next useful step is therefore not immediate extra scale, but added metastability.

This means:

- more internal fluctuation,
- more temporary reversals,
- more partial recovery,
- and more local instability before the final route becomes clear.

## Core purpose

The metastable layer should make the model more alive without making it unreadable.

It should help the experiment show:

- delayed route recognition,
- temporary false stabilization,
- partial re-entry followed by renewed weakening,
- and uneven timing between different parts of the field.

## What metastability should not mean

It should not mean:

- random noise added everywhere without structure,
- total loss of route distinction,
- or replacement of diagnosis by chaos.

The purpose is not to destroy interpretability.

The purpose is to make the route dynamics less artificially clean.

## Minimal metastable mechanisms

At the first stage, the metastable layer could be built from three small additions.

### 1. Soft route wavering

Instead of one smooth route pressure curve, allow small oscillatory or delayed local wavering around the main route.

This would model:

- crisis pressure that does not arrive perfectly smoothly,
- local hesitation,
- and temporary over- or under-expression of the same route.

### 2. Partial relapse window

After initial recovery, allow a temporary relapse tendency before the system settles.

This would model:

- false recovery,
- weak re-entry,
- or a field that gathers briefly and then partially loosens again.

### 3. Group-asynchronous response

Allow different groups or bond classes to respond with slightly different timing.

This would model:

- one subgroup recovering early,
- another subgroup lagging,
- and bridge structure being stressed during that mismatch.

## Minimal implementation sketch

At the simulation level, the simplest working additions would be:

- a small oscillatory modulation of `route pressure (давления маршрута)`,
- a delayed relapse term after the main crisis window,
- and a small group-dependent timing offset in how route pressure is applied.

These additions should stay weak enough that the underlying route still remains identifiable.

## Why this is the right next step

The current model already distinguishes routes.

The next thing it needs is not more diagnosis of idealized crises, but more realistic crisis texture.

Metastability can provide exactly that:

- not new route categories,
- but richer behavior inside the existing route categories.

## What we would hope to see

If this layer works, the model should begin to show:

- short-lived false stabilization,
- repeated entry into `restored weak (восстановленно-слабое)` states,
- temporary subgroup imbalance,
- and more lifelike long tails.

But it should still preserve:

- shock as the most acutely recoverable route,
- drift as the most tail-heavy weakening route,
- and distortion as the most pathology-prone route.

## Minimal conclusion

The metastable layer is the next natural refinement because it adds life to the current route architecture without forcing a new theory.

It should make the model:

- less clean,
- more realistic,
- and more revealing about where re-entry succeeds only temporarily.
