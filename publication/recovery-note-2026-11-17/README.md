# Исследовательская заметка, версия 1.0.0

**Опубликована 18 ноября 2026: [10.5281/zenodo.24332972](https://doi.org/10.5281/zenodo.24332972)**. В записи доступны PDF 1.0.0, комплект 1.0.1 и контрольные суммы; все три файла совпадают с локальными. [Текущая ссылка для цитирования](CITATION.md).

Подготовлена для публикации 17 ноября 2026 по трём завершённым сериям 8 октября. [Читать текст](note.ru.md). PDF находится в `../../output/pdf/local-recovery-note-ru.pdf`.

## Что уже собрано

Связная русская заметка: задача, модель, три последовательных сравнения, численные результаты, один явно обозначенный постфактум контрпример, ограничения, открытые вопросы и ссылки на закреплённые открытые источники. Авторские образы, онтологические формулировки и сильные общие заявления в текст не включены. Публикация не выдаёт реализованный фрагмент за весь цикл VI.

Файлы `audit_note.py` и `evidence.json` связывают ключевые числа с архивными CSV; средние и парные разности пересчитываются из исходных строк с нужным усреднением по seed. Интервалы сверяются с архивными таблицами, но не рассчитываются заново. `quick_demo.py` запускает один заранее выбранный мир и три правила без записи в архив. Подробности: [REPRODUCE.md](REPRODUCE.md).

## Редакционная оценка

Материала достаточно для небольшой технической заметки с открытыми результатами. Самостоятельная новизна алгоритма и готовность журнальной статьи этой сборкой не устанавливаются. Содержательный центр - различие наблюдаемой нехватки, доступной помощи, её времени и результата для адресата.

Авторская строка по пожеланию Katia: **SymbiosisK (Katia) & ChatGPT / Codex (OpenAI)**. Вклад ChatGPT (Лиры) в разбор пакета и рекомендации научной редакции раскрыт отдельно от вклада Codex в анализ, код проверок, текст и сборку. Точные роли в ранних сессиях без подтверждения не приписываются конкретной модели. Условия: MIT для кода и CC BY 4.0 для текста и данных. Замечания учтены в версии 1.0.0; см. REVIEW_RESPONSE.md в пакете. Заметка и комплект размещены Katia на Zenodo; фактический DOI добавлен в текущий CITATION.md. При заявлении более общего результата потребуются новые проверки.
