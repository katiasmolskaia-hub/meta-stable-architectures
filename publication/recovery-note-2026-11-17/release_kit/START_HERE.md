## Хочу попробовать

Нужны Python и NumPy. Из корня распакованного пакета:

```sh
python -m pip install -r requirements.txt
python run_demo.py
```

Это три правила на одном заранее выбранном мире. Пример сверяет результат с архивом и не перезаписывает данные. Один мир не заменяет итоговое сравнение по seed. Подробности и полные команды: [воспроизведение](publication/recovery-note-2026-11-17/REPRODUCE.md).

## Хочу проверить архив

```sh
python verify_package.py
python publication/recovery-note-2026-11-17/audit_note.py
```

Первая команда проверяет SHA-256 файлов. Вторая пересчитывает ключевые средние и парные разности из сохранённых CSV; bootstrap-интервалы заново не строит. `VALIDATION.json` фиксирует проверки, выполненные при сборке пакета.

В `VALIDATION.json` раздел `file_counts` различает исходные архивные файлы трёх серий, все файлы по манифесту комплекта и общее число файлов ZIP с самим манифестом. Исходный архив - часть комплекта; эти числа не нужно складывать. Проверяющий скрипт автоматически сопоставляет счётчики с обоими манифестами.
