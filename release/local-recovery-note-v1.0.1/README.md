Готовые файлы находятся во вложениях релиза. Большой ZIP не дублируется в истории Git.

- [Читать PDF](https://github.com/katiasmolskaia-hub/meta-stable-architectures/releases/download/recovery-note-v1.0.1/local-recovery-note-ru.pdf).
- [Скачать самостоятельный ZIP](https://github.com/katiasmolskaia-hub/meta-stable-architectures/releases/download/recovery-note-v1.0.1/local-recovery-note-v1.0.1.zip), распаковать и открыть `START_HERE.md` внутри.
- [Контрольные суммы SHA-256](https://github.com/katiasmolskaia-hub/meta-stable-architectures/releases/download/recovery-note-v1.0.1/SHA256SUMS.txt).
- [Отчёт проверки комплекта](https://github.com/katiasmolskaia-hub/meta-stable-architectures/releases/download/recovery-note-v1.0.1/PACKAGE_CHECK.json).

PDF 1.0.0 и комплект 1.0.1 побайтово совпадают с файлами, опубликованными на Zenodo. В релиз также приложены исходные README, RELEASE_NOTES и ZENODO_UPLOAD из внешней папки комплекта, чтобы каждый файл из исходного SHA256SUMS.txt можно было проверить. Исторические формулировки в них отражают момент сборки до размещения. Актуальные [сведения для цитирования](../../publication/recovery-note-2026-11-17/CITATION.md) хранятся отдельно.
