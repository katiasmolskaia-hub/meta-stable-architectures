# Сохранённые результаты

Здесь хранятся точные копии итоговых папок из `outputs/`, чтобы результаты были доступны в GitHub без повторного расчёта. Архив не содержит зависимостей Python, временных окружений и промежуточных неисправленных вариантов.

| Папка | Опыт |
|---|---|
| [bridge_feedback_v2](bridge_feedback_v2) | Обратная связь и мостовой жизненный цикл |
| [bridge_buffer_2026-10-03](bridge_buffer_2026-10-03) | Буфер и стрессовое разрешение |
| [bond_rewiring_2026-10-03](bond_rewiring_2026-10-03) | Выбор соседей по опыту |
| [bond_rewiring_scale_cost_2026-10-03_v2](bond_rewiring_scale_cost_2026-10-03_v2) | Размер сети и цена перестройки |
| [bond_recovery_stop_2026-10-04](bond_recovery_stop_2026-10-04) | Продолжение или пауза после восстановления |
| [local_support_signal_2026-10-04](local_support_signal_2026-10-04) | Автономные локальные запросы |
| [support_pulse_2026-10-04](support_pulse_2026-10-04) | Фоновый пульс и запросы при общем бюджете |

`manifest.json` содержит SHA-256 каждого архивного файла, кроме самого манифеста и этого указателя. Git сохраняет байты архива без преобразования переводов строк (`.gitattributes`), чтобы хеши снимков оставались проверяемыми на разных платформах.

CSV содержат все сохранённые строки итоговых серий, а не выборку успешных запусков. Интервалы в отчётах исследовательские: учитывать небольшой набор сценариев, множественные сравнения и численную чувствительность.

Отчёты с выводами и протоколы: [исследовательский указатель](../RESEARCH_STATUS.md).
